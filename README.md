# 🎬 Netflix Clone

A fully responsive Netflix-inspired landing page built using **HTML5 and CSS3**. This project recreates the visual experience of Netflix with a modern dark theme, cinematic hero section, movie categories, interactive hover effects, and smooth CSS animations.

## 🌐 Live Demo

[View Live Website](https://netflixclone11.tiiny.site)

## 📸 Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Netflix-Inspired UI:** Dark theme with a cinematic layout.
- **Hero Section:** Large background image with gradient overlays and action buttons.
- **Movie Categories:** Separate sections for trending movies, popular movies, and TV shows.
- **Hover Animations:** Smooth zoom effects on movie cards.
- **CSS Animations:** Fade-up and slide-down entrance animations.
- **Interactive UI:** Animated buttons, navigation links, and search bar.
- **Horizontal Scrolling:** Scrollable movie collections.
- **Responsive Navigation:** Adapts to smaller screen sizes.
- **Accessibility:** Includes reduced-motion support.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, transitions, and responsiveness.
- **CSS Media Queries** – Responsive layouts for different screen sizes.
- **Unsplash** – Background and movie imagery.

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Netflix-Clone
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in VS Code.
